# Готовые шаблоны и примеры проектов (`projects/examples/`)

Примеры вынесены из автоматического сидирования рабочей БД (`hub.db`) в этот каталог. Вы можете импортировать их в один клик с Дашборда или через командную палитру `Ctrl+K` (`POST /api/projects/import_examples`).

## Состав примеров

1. **`heartbeat-daemon`** (`type = service`, 24/7 демон)
   - Показывает работу постоянного процесса в собственной группе `PGID` с записью stdout напрямую в файловый дескриптор лога (`buffering=0`, без `SIGPIPE` при перезапуске Hub) и сохранением состояния между рестартами через `hub.state.set("ticks", ...)`.
2. **`web-status-api`** (`type = web`, HTTP API бэкенд)
   - Демонстрирует запуск веб-сервиса на выделенном порту `$PORT` (`18081`), автоматический опрос эндпоинта `/health` супервизором и подсчёт запросов в `hub.state`.
3. **`sms-auth-bot`** (`type = job`, интерактивный ввод `hub.ask()`)
   - Демонстрирует перевод процесса в статус `WAITING_INPUT` и получение 2FA/СМС-кода из веб-баннера панели или ответа (`Reply`) в Telegram.
4. **`cookie-checker-job`** (`type = job`, Cron-парсер с куки)
   - Демонстрирует чтение куки из `hub.secret("<project>_cookies")` и вызов `hub.cookies_expired(...)` при протухании сессии.
5. **`backup-sync-job`** (`type = job`, периодическая задача)
   - Пример фоновой задачи синхронизации и обслуживания.
