# История изменений / Changelog

Все значимые изменения проекта **Hub (`VoidAruta/Hub-server`)** документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [1.0.0] - 2025-05-12

### Добавлено (Added)
- **Ядро управления процессами (`hub/process_mgr.py`):**
  - Запуск проектов (`service` и `job`) в изолированных группах процессов через `os.setsid()` и гарантированное завершение всего дерева дочерних процессов через `os.killpg()` (`SIGTERM` -> ожидание -> `SIGKILL`).
  - Прямое перенаправление `stdout`/`stderr` в файловый дескриптор лога (`buffering=0`) без использования `subprocess.PIPE`, что позволяет дочерним демонам переживать перезапуск самого Hub.
  - Восстановление выживших процессов (`recover_running_processes`) при старте Hub со сверкой `psutil.Process(pid).create_time()` для защиты от повторного использования PID ядром Linux.
  - Контроль лимита оперативной памяти (`max_ram_mb`) путём суммирования `RSS` всей группы процессов `PGID` без установки `RLIMIT_AS` (предотвращает падение Node.js/V8, JVM и Chromium).
  - Сохранение дополнительных групп Android (`aid_inet` = `3003`, `aid_net_raw` = `3004`) при понижении привилегий до пользователя `runner`.
- **Интерактивный CLI-терминал и двусторонний `stdin`:**
  - Полноценный веб-терминал внутри каждого проекта для выполнения команд в рабочем каталоге (`pip`, `git`, `python3`, `npm`) и прямой отправки интерактивного ввода (2FA-кодов, паролей, ответов `y/n`) в `stdin` запущенного процесса через именованный канал (`FIFO`).
- **Интерактивный захват веб-сессий (`hub/web_auth_mgr.py`):**
  - Встроенный удалённый браузер во вкладке «Куки и сессии» для ручного прохождения логина, 2FA и антибот-проверок (Cloudflare Turnstile, hCaptcha, reCAPTCHA) с автоматическим извлечением всех cookies (включая `HttpOnly`) в `data/cookies/{name}.json` и генерацией готового кода для Python (`hub_sdk`) и Node.js.
- **Создание проектов из GitHub:**
  - Клонирование публичных и приватных репозиториев (`git clone --depth 1`), автоматическое обнаружение `requirements.txt` и `package.json`, автоподстановка команды запуска.
- **Локальный Python SDK (`hub_sdk`):**
  - Получение секретов (`get_secret`), загрузка и сохранение cookies (`load_cookies`, `save_cookies`), чтение/запись KV-хранилища (`kv_get`, `kv_set`), отправка уведомлений в Telegram (`notify`), межпроектные вызовы (`trigger_project`) и публикация статуса на карточку проекта (`set_status`).
- **Телеметрия железа Android (Xiaomi Poco X3 NFC `surya`):**
  - Чтение `/sys/class/power_supply/battery/*` и `/sys/class/thermal/*` (SoC, CPU, RAM, ZRAM/Swap, температура и контроллер заряда батареи 45–55%).
  - 60-секундный TTL-кэш расчёта размера директорий проектов для минимизации износа UFS-памяти и нагрузки на I/O.
- **Гигиена репозитория и CI/CD:**
  - Полная очистка `.gitignore`, вынос шаблонных проектов в `projects/examples/`, GitHub Actions workflow для автоматической сборки статического фронтенда в `hub/static/` (не требует Node.js на телефоне).
