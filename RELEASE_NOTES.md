# Beacon v2.3.0 — Release Notes

Крупное обновление автономной контейнер-free панели управления процессами **Beacon**: усиленная безопасность, массовое управление парком, Git-деплой и откат, локальные снимки кода, каскадные зависимости, SLA-аналитика, Prometheus/Grafana-метрики, карта портов и живой инспектор дерева процессов PGID.

Все изменения сохраняют **5 архитектурных инвариантов Beacon**: изоляция процессов по `PGID` (`os.setsid` / `os.killpg`), прямой вывод логов в файловый дескриптор (`buffering=0` без `SIGPIPE`), подхват выживших процессов при рестарте панели, учёт памяти по сумме RSS группы `PGID` (без `RLIMIT_AS`) и потребление самой панели `< 80 МБ ОЗУ`.

---

## Основные нововведения

### 1. Безопасность, RBAC и Production-режим
- **Строгая матрица RBAC (`viewer` / `operator` / `admin`)**: закрыты пути обхода и добавлена поддержка ролей для всех новых read-only и операционных маршрутов (поиск логов, SLA, Prometheus, карта портов, дерево PGID, массовые операции, режим обслуживания).
- **Чистый Production-режим**: переключатель на дашборде скрывает тестовые проекты и панель быстрых самопроверок SDK, оставляя только рабочую телеметрию.
- **Умный `.env`-импорт и миграция секретов**: пакетная вставка `.env`-текста с автоматическим определением чувствительных ключей (`SECRET`, `TOKEN`, `PASSWORD`, `API_KEY` и др.) и переносом их в файловый сейф (`chmod 0600`).
- **Пресеты прав AI-токенов (MCP / REST v1)**: быстрые профили (`Только чтение`, `Под присмотром`, `Автономный`) для мгновенной безопасной настройки доступа ИИ-агентов.
- **Защита экспорта аудита**: экранирование формул Excel/Google Sheets (CSV Formula Injection) при выгрузке журнала аудита.

### 2. Операционное управление парком и уведомления
- **Массовые операции над проектами (`POST /api/projects/batch_action`)**: групповой запуск, остановка и перезапуск отфильтрованных проектов на дашборде в 1 клик.
- **Редактор групп / тегов проектов (`PROJECT_GROUP`)**: назначение группы проекта прямо в настройках с быстрыми пресетами (`#Продакшн`, `#Веб/API`, `#Боты 24/7`, `#Парсеры`, `#Стейджинг`) для фильтрации и пакетного управления.
- **Многоканальные уведомления**: добавлена нативная поддержка **Discord** и **Slack** webhook-каналов наряду с Telegram и ntfy.
- **Режим тишины (Maintenance Mute, `POST /api/settings/maintenance`)**: временное отключение алертов на время плановых работ с индикатором в шапке панели.
- **Инспектор вебхуков и проброс payload**: передача входящего JSON-тела вебхука в переменные окружения процесса (`BEACON_WEBHOOK_PAYLOAD`, `BEACON_WEBHOOK_EVENT`), история последних вызовов (`GET /api/projects/{id}/webhooks`) и кнопка тестового запуска (`POST /api/projects/{id}/webhook_test`).
- **Улучшенные логи и расписание**:
  - Фильтрация логов по уровню (`Все`, `WARN + ERROR`, `Только ERROR`) с сохранением многострочных Python/Node.js stack trace.
  - Готовые пресеты расписания (`Каждые 5 мин`, `Каждый час`, `Ежедневно в 03:00`, `По будням` и др.) и живой прогноз следующего запуска.

### 3. Деплой, версионирование кода и зависимости запуска
- **Git Auto-Deploy и откат в 1 клик**:
  - Панель статуса репозитория (`GET /api/projects/{id}/git_info`): текущая ветка, изменённые файлы и список последних коммитов.
  - Обновление (`POST /api/projects/{id}/git_pull`, `git pull --ff-only`) с опциональным автоперезапуском и опцией `AUTO_GIT_PULL` перед стартом.
  - Безопасный откат к выбранному коммиту (`POST /api/projects/{id}/git_rollback`) с перезапуском процесса.
- **Локальная история версий файлов (без Git)**:
  - Автоматическое сохранение до 12 локальных снимков файла перед каждым изменением через встроенный редактор (`GET /api/projects/{id}/files/snapshots`).
  - Мгновенный просмотр и восстановление любой предыдущей версии (`POST /api/projects/{id}/files/restore_snapshot`).
- **Каскадные зависимости (`DEPENDS_ON`)**: автоматический запуск зависимых сервисов перед стартом текущего проекта с защитой от циклических зависимостей и дублирующих запусков.
- **Пиковое потребление памяти (`peak_rss_mb`)**: отслеживание пикового RSS за текущий запуск рядом с текущим потреблением ОЗУ для быстрого выявления утечек памяти.

### 4. Наблюдаемость, SLA-аналитика и Prometheus
- **Глобальный поиск по логам всех проектов (`GET /api/logs/search`)**:
  - Новая вкладка **«Поиск по логам»** на дашборде с фильтрацией по тексту, уровню и проекту.
  - Чтение ограничено хвостом последних логов (до 256 КБ на файл) для сохранения бюджета `< 80 МБ ОЗУ`, с маскировкой секретов и переходом к проекту в 1 клик.
- **SLA и аналитика стабильности (`GET /api/analytics/summary`)**:
  - Новая вкладка **«SLA и Стабильность»** за `24ч / 7д / 30д`: общий SLA %, количество запусков, сбоев и OOM Kill, средняя длительность, пиковый RSS и 10-сегментная визуальная лента последних запусков по каждому проекту.
- **Экспорт метрик Prometheus / OpenMetrics (`GET /api/metrics`)**:
  - Поддерживает авторизацию как по браузерной сессии (`viewer+`), так и по `Authorization: Bearer <AI-токен с правом read>` для скрейпинга из Prometheus/Grafana.
  - Экспортирует `beacon_hub_rss_bytes`, метрики хоста (RAM, CPU, диск) и метрики по каждому проекту (`beacon_project_up`, `beacon_project_rss_bytes`, `beacon_project_peak_rss_bytes`, `beacon_project_cpu_percent`, `beacon_project_runs_total`).
  - В разделе **Настройки → Аудит и Prometheus** добавлены живой предпросмотр метрик и копируемый фрагмент `prometheus.yml`.
- **Экспорт журнала аудита (`GET /api/system/audit/export`)**: выгрузка логов безопасности в форматах **CSV** и **JSON** (только для администратора).

### 5. Сеть, порты и инспекция процессов
- **Карта TCP-портов сервера (`GET /api/system/ports`)**:
  - Вкладка **«Карта портов»** на дашборде: сканирует слушающие TCP-сокеты (через `psutil` с резервным чтением `/proc/net/tcp` и `/proc/net/tcp6` без root-прав).
  - Показывает владельца каждого порта (`Панель Beacon`, `Проект Beacon`, `Резерв`, `Внешний процесс`), выделяет **конфликты портов** и подсказывает ближайший свободный порт (`18080+`).
- **Живое дерево процессов группы PGID (`GET /api/projects/{id}/processes`)**:
  - Кнопка **«Дерево PGID»** в шапке запущенного проекта отображает все дочерние процессы и воркеры внутри его `PGID` (`PID`, `PPID`, метка `ROOT`, имя, статус, RSS в МБ, очищенная командная строка).
  - Полная совместимость как с нативным `psutil`, так и со встроенным `/proc`-слоем совместимости Beacon.
- **Генератор конфигов Reverse Proxy (`Nginx` / `Caddy` / `Cloudflared`)**:
  - В настройках `Web / API (:PORT)` проекта встроен генератор готовых конфигов для публикации сервиса на свой домен с поддержкой WebSocket/SSE, авто-TLS (Caddy) и Cloudflare Tunnel (`config.yml`).
