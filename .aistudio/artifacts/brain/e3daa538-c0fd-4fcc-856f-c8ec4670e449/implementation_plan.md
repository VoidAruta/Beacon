# План развития и оптимизации панели Hub (`/opt/hub`) под Poco X3 NFC (Root + Ubuntu 24.04 chroot)

Панель **Hub** проектируется под вашу конкретную аппаратную конфигурацию:
* **Устройство**: **Xiaomi Poco X3 NFC (`surya`, Snapdragon 732G, `aarch64`, Root-права)**.
* **Режим питания**: постоянное подключение к зарядке с Root-контроллером удержания заряда в коридоре **45% — 55%** (зарядка до 55% → отключение подачи тока → плавный разряд до 45% → включение зарядки по кругу).
* **Среда**: Ubuntu 24.04 `chroot`, локальный прокси `127.0.0.1:10808`, строгий бюджет ОЗУ панели (`< 80 МБ` в фоне), бережная работа с UFS 2.1 флеш-памятью.

Ниже представлен обновлённый план с учётом **интерактивной авторизации на сайтах с Антиботом**, **установки программ из GitHub с вводом команд** и **умного контроля питания 45–55% для Poco X3 NFC**.

---

## 1. НОВОЕ: Интерактивная авторизация прямо на сайте (обход Антибота и привязка сессии)

Когда простые экспортированные куки из домашнего ПК не подходят (из-за привязки Cloudflare / DataDome / гео-IP / TLS-отпечатка / `localStorage` и `IndexedDB`), авторизоваться нужно **непосредственно с самого телефона-сервера через его прокси и его браузерный профиль**.

### Как это будет устроено (без расхода ОЗУ в простое):
1. **Изолированный профиль браузера внутри проекта (`browser_profile/` + `storage_state.json`)**:
   * У каждого проекта, помимо `cookies.json`, создаётся папка полного браузерного профиля (`projects/<имя>/browser_profile/`) и снимок `storage_state.json` (включающий **Cookies + LocalStorage + SessionStorage + точный User-Agent**).
2. **Режим «Интерактивный вход на сайт» (On-Demand Web Auth прямо в панели)**:
   * Во вкладке **«2. Куки, Авторизация и Telegram»** появляется блок **«Авторизация на сайте (Антибот / Капча / Вход)»**:
     * Вы вводите URL нужного сайта (например, `https://...`), выбираете прокси (системный `10808` или индивидуальный прокси проекта) и нажимаете **«Открыть сайт для входа»**.
     * Панель временно поднимает браузерную сессию (Playwright Chromium / Xvfb на `aarch64`) и транслирует интерактивное окно страницы прямо внутрь веб-интерфейса панели:
       * Вы прямо мышкой/с экрана телефона кликаете по полям, проходите капчу/Cloudflare, вводите логин, пароль и код 2FA.
       * Встроенная панель управления сессией позволяет: **Кликнуть по координатам**, **Ввести текст в активное поле**, **Прокрутить страницу**, **Перейти по URL** и видеть живой экран сайта.
     * Как только вы вошли в аккаунт и нажали **«Сохранить сессию и закрыть браузер»**:
       1. Панель автоматически выгружает свежие куки в `cookies.json`, полный слепок `storage_state.json` (вместе с `localStorage`) и сохраняет кэш профиля в `browser_profile/`.
       2. Браузерный процесс **полностью убивается (`os.killpg`)**, освобождая все 300–500 МБ ОЗУ обратно системе!
       3. Ваш скрипт при следующих запусках подхватывает уже готовую «прогретую» сессию с тем же отпечатком и тем же прокси.

## 2. НОВОЕ: Установка программ из GitHub и встроенная консоль команд (Терминал проекта)

Многие готовые боты, парсеры и утилиты выложены на GitHub, требуют клонирования (`git clone`), установки зависимостей (`pip install -r requirements.txt`) и первичной настройки через консоль.

### Как это будет реализовано:
1. **Создание проекта напрямую из GitHub (`Git Clone` в 1 клик)**:
   * В окне **«Создать проект»** появится вкладка **«Из GitHub репозитория»**:
     * Достаточно вставить ссылку вида `https://github.com/автор/репозиторий` (и при необходимости токен для приватного репо или ветку).
     * Панель сама выполнит `git clone` **через прокси `127.0.0.1:10808`** в папку `/opt/hub/projects/<имя>`, автоматически найдёт точку входа (`main.py`, `bot.py`, `app.py`, `index.js` или `run.sh`) и прочитает `README.md`, чтобы показать вам шпаргалку по запуску.
2. **Встроенная «Консоль и Команды» внутри каждого проекта**:
   * В карточке проекта добавляется удобный блок/вкладка **«Терминал и Установка (Git / Pip / CLI)»**:
     * **Быстрые кнопки в 1 клик** (для тех, кто не хочет писать команды вручную):
       * `🔄 Обновить из GitHub (git pull)`
       * `📦 Установить зависимости (pip install -r requirements.txt)`
       * `🐍 Создать изолированный .venv и поставить пакеты`
       * `🔑 Дать права на запуск (chmod +x *.sh)`
     * **Полноценная строка ввода команд (Shell внутри папки проекта)**:
       * Вы можете ввести любую команду (например: `pip install aiohttp`, `python3 main.py --login`, `git status`, `ls -la`), причём переменные прокси (`HTTP_PROXY=http://127.0.0.1:10808`) подключаются автоматически, чтобы `git` и `pip` качали пакеты без блокировок.
     * **Интерактивный ввод (`stdin`) в работающий процесс**:
       * Если скачанная с GitHub программа при первом запуске пишет в консоль *«Введите номер телефона:»* или *«Выберите режим [1/2]:»* (и не использует `hub.ask()`), вы сможете **отправить ответ прямо в стандартный поток ввода (`stdin`) процесса** из окна логов/терминала!

## 3. Адаптация под Poco X3 NFC (Root + контроллер заряда 45%–55%)

Поскольку ваш **Poco X3 NFC** постоянно лежит на зарядке с Root-ограничителем **45% ↔ 55%**, обычный мониторинг батареи на других панелях выдавал бы ложную тревогу каждый раз, когда контроллер на 55% отключает зарядку и телефон переходит в статус `Discharging` до 45%.

### Специальная логика питания для вашей схемы 45%–55%:
1. **Чтение аппаратных датчиков Poco X3 NFC (`surya`) из `/sys/class/power_supply/` и `/sys/class/thermal/`**:
   * Заряд батареи (`battery/capacity`), статус контроллера (`battery/status`), физическое наличие кабеля (`usb/online` или `ac/online`), температура батареи (`battery/temp`) и температура процессора Snapdragon 732G (`thermal_zone*/temp`).
2. **Умный режим «Удержание заряда 45%–55% (Root Battery Limit)»**:
   * В настройках питания панели задаётся ваш рабочий коридор (по умолчанию **мин. 45% — макс. 55%**, порог тревоги **< 40%**):
     * Пока заряд находится в пределах **43% — 57%**, даже если статус `Discharging` (идёт плавный спуск с 55% до 45%), панель отображает зелёный статус: **`Питание в норме: цикл 45–55% (51%, плавный разряд)`** и **не шлёт** ложных уведомлений.
     * **Тревога «Пропало питание / Сбой зарядки!»** срабатывает только если:
       1. Заряд упал **ниже 40%** (значит, реально выключили электричество дома, отошёл кабель или завис Root-модуль контроллера зарядки и не включил ток на 45%).
       2. При падении заряда **ниже 20%** панель автоматически ставит на паузу некритичные скрипты, чтобы телефон не выключился в ноль и не повредил файловую систему `chroot`.
     * **Контроль нагрева**: если батарея нагрелась выше **42°C** или CPU выше **55°C**, панель пришлёт предупреждение в Telegram.

## 4. Технические улучшения и организация (из основного плана)

1. **Защита флеш-памяти Poco X3 NFC (UFS 2.1)**:
   * Кэширование расчёта размера папок проектов (`_calc_dir_size`) с TTL **60 секунд** вместо обхода диска каждые 2 секунды.
2. **Реальный двусторонний Telegram-бот панели (`getUpdates` через прокси `10808`)**:
   * Ответ на запросы `hub.ask()` через обычный **Reply** в Telegram + команды `/status` (покажет заряд Poco X3, температуру, ОЗУ и список скриптов), `/projects`, `/run <имя>`, `/stop <имя>`.
3. **Индивидуальный прокси на уровне проекта + проверка порта `10808`**:
   * Выбор для каждого проекта: *Общий прокси панели (`127.0.0.1:10808`)* / *Свой индивидуальный прокси (`http/socks5`)* / *Без прокси*, плюс живой индикатор доступности прокси `10808` в шапке.
4. **Клонирование проектов, Группы/Теги и Очередь по ОЗУ**:
   * Фильтрация проектов по группам (`Боты`, `Парсеры`, `GitHub`, `Система`), клонирование проекта в 1 клик под второй аккаунт, экспорт в `.zip` и защита от одновременного запуска слишком большого числа тяжёлых задач.
